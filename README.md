# Python Interview Prep — Free Sample Programs

25 complete Python practice programs for interviews, free. Every program here is small, complete and runnable — copy one into your editor, run it, then close the file and write it again from memory. That blank-editor habit is what interviews actually test.

These 25 programs are the free first section of **Python Interview Prep** (140 programs + 100 interview questions, every program printed with its real output).

Programs 1–25: warm-ups and logic classics — swapping variables, even/odd, largest of three, sum of digits, reverse a number, palindrome checks, Fibonacci, prime numbers, factorial, Armstrong numbers, multiplication tables, and more.
